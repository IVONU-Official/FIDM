# Code of Conduct

FIDM project spaces are intended to be respectful, practical, and welcoming to everyone, regardless of experience, identity, background, or viewpoint.

Examples of behavior that supports this standard include using considerate language, discussing technical disagreements constructively, accepting review feedback, and focusing criticism on ideas and code.

Harassment, insults, discriminatory remarks, unwanted personal contact, and disruptive conduct are not acceptable. Project maintainers may edit or remove content and may restrict participation when conduct harms the project community.

For conduct concerns, contact the repository maintainers privately through GitHub. Please include relevant context and links when possible.
